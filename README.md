Dracula the Board Game (Digital Version) by Mollefunk1

## Description
Dracula-boardgame is a web-based social deduction game inspired by the classic Dracula story. This application allows players to immerse themselves in a strategic and thrilling adventure where they must make decisions to survive or conquer as Dracula.

This is meant to work as a simulation of the physical version of the board game, and not as a standalone game.

This game is still a WIP, and is not functioning as of this time, but will be in the future! 

## Features
- Interactive gameplay with multiple players
- Strategic decision-making elements
- Immersive storyline and graphics
- User-friendly interface
